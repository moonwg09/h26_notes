웹 브라우저(클라이언트)

클라이언트가 먼저 서버에 요청(request)을 한다.
서버는 요청 받은 것을 클라이언트에게 응답(response)한다

웹에서는 요청을 할때 url(프로토콜://ip:port/경로)을 사용한다
response할때는 text형태로 날라온다(<html></html>) 
text뿐만 아니라 json, xml로도 response한다


해석기관이 클라이언트면 프론트엔드
서버면 백엔드

웹 표준 : html, css, javascript

html : 정적인 페이지(어느 누가 어디에서 봐도 똑같이 나온다)
html에 javascript를 넣어서 만든 것 : 동적인 페이지

html은 뼈대를 만들어주는 것이고(내용과 구조) css는 세부적인 내용을 표현해주는 것(디자인과 색상)
javascript는 동작(동적제어)들을 해준다.
=> 각자의 역할

tag에서 inline으로 id, class, style, name을 사용한다
<div name, id, class, style = "value" >
name => form tag에서만 사용

html 기본 태그 4가지 : html, head, body, title
