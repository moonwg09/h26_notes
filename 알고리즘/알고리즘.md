해싱 :
임의의 길이를 가진 데이터를 고정된 길이의 데이터(해시 값)로 변환하는 과정
 =>키값에 대한 산술적 연산에 의해 레코드가 저장될 위치(point)를 계산

key => 해시 함수 => 해시 값


해시 테이블(자료구조)
데이터의 해시값을 테이블 내의 주소(index)로 사용하는 자료 구조
버킷 : 버킷의 크기(소수 선택)

해시 함수(이런 게 있다 정도)
- 나눗셈법
- 중간제곱법
- 폴딩법
- 숫자 분석법
- 기수변환법

해시테이블의 구조, 충돌과 오버플로

해시는 충돌이 발생할 수 있다 => 옆 슬롯에서 저장한다(배열이나 연결 리스트로 만든다)

체이닝(연결 리스트), 선형 조사법(배열)


해시 자료구조의 특징
-시간 복잡도가 o(1), 최악의 경우(충돌 발생) o(n)
-단방향으로 동작 (key로 데이터를 찾지만, 데이터로 key를 찾지 못함)
